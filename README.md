## 📖 Описание

**ru-cidr** – это перечень провайдеров и их **IP-адресов**, которые:

*   Проходят фильтры мобильных операторов.
*   Работают даже при ограничениях мобильного интернета.
*   Годятся для прокси или мостов.

Можно взять **любой IP из списка** и проверить, как он работает.

---

## ❓ Зачем это надо

Сейчас с мобильным интернетом в России не всё просто:

*   Обычные VPN часто не подключаются.
*   Бесплатные прокси быстро блокируют.
*   Система DPI отсеивает кучу трафика.

Использование IP из этих списков даёт возможность:

*   Обходить блокировки DPI.
*   Получать стабильное соединение.
*   Использовать прокси и туннели без проблем.

---

## 🧩 Как это можно использовать

| Случай       | Описание                                                                                           |
| :------------ | :------------------------------------------------------------------------------------------------- |
| 🔁 BRIDGE     | Подключение через разрешённый IP, чтобы выйти в интернет за границей.                            |
| 🌍 Direct     | Прямое подключение к серверу, который в белом списке.                                          |
| 🛡 Proxy      | SOCKS или HTTP прокси.                                                                          |
| 🚀 Tunnel    | V2Ray, Xray, ShadowSocks или Vless.                                                              |

---

## 🔗 Как работает BRIDGE

[ Клиент ]

|

| (Мобильный интернет)

v

[ Прокси / Мост-сервер ] (IP из белого списка)

|

| (Свободный интернет)

v

[ Зарубежный сервер ] (За пределами России)

**Как это работает:**

1.  Клиент подключается к прокси-серверу с IP из белого списка.
2.  Мобильный оператор даёт добро на соединение.
3.  Прокси отправляет трафик на сервер за границей.
